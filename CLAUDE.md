# Grimório de Søren Frostgaard

App publicado no GitHub Pages para uma campanha de D&D 2024 (5.5). O `index.html` é gerado: edite `src/` e rode `npm run build`. Rode `npm test` antes de publicar.

## Fontes de regras

- Números atuais do Søren: objetos `SOREN` e `SOREN_SPELLS` em `src/data/soren.js`.
- Resumo de regras e próximos níveis: `docs/guia-regras-soren.md`.
- Os livros **não** estão neste repositório e não devem ser adicionados, nem como PDF nem como texto extraído. Ele é público. `private/` é ignorada pelo git e guarda o que o extrator gera; nunca a inclua em commit.
- Em sessão na nuvem, não há acesso aos livros. Se a dúvida exigir o texto exato, avise o usuário para consultá-la na sessão local do espaço RPG, em vez de responder de memória.
- Tudo o que entrar aqui deve ser resumido com palavras próprias, sem trechos copiados.
